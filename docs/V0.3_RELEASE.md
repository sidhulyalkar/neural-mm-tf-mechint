# v0.3: Interpretability to Control

v0.3 advances Neural MechInt from a causal research laboratory into an experimental control stack for custom open-model deployments.

## New packages

- `mechstate`: interpretable state signals, trajectories, calibration, receipts.
- `mechguard`: monitors, policies, conditional steering, deployment profiles.
- `mechtune`: causal feedback selection, counterfactual data, representation losses, Circuit-LoRA planning, intervention distillation.
- `mecheval`: behavioral, mechanistic, causal, model-diff, and deployment scorecards.
- `applications.grounded_rag`: reference evidence-vs-user-pressure deployment.

## What remains experimental

No repository result should imply that a named Gemma circuit has been established until real model runs, held-out controls, and interventions have been completed. v0.3 builds the machinery and scientific protocol for those experiments.

## v0.4 target

Integrate real Gemma Scope 2 feature/transcoder adapters, produce cross-layer attribution artifacts, calibrate the first real MechState bundle on Gemma 3, and run a shadow-mode grounded-RAG benchmark across model sizes.
