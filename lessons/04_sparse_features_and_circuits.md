# Lesson 4 — From dense vectors to sparse circuits

Dense residual directions can be causally effective while still being difficult to interpret. Sparse autoencoders and transcoders offer a more granular vocabulary of features.

## Questions to ask

- Which sparse features explain the dense pressure direction?
- Which features are merely correlated with the prompt wording?
- Which features have direct downstream attribution to the answer?
- Can a small feature subset reproduce the dense patching effect?
- Does removing that subset destroy the behavior?

The final two questions convert a feature story into a circuit claim.
